# 관리비버

관리비 확인이라는 일상 행동 속에 사회안전망의 접점을 심는 모바일 우선 웹앱입니다.

## 실행

```bash
npm install
npm run dev
```

## 데모 로그인

- 이메일: `demo@gwanribeaver.kr`
- 비밀번호: `beaver1234`

## Netlify

Netlify에서 이 폴더를 Base directory로 지정하면 `netlify.toml` 설정에 따라 배포됩니다.

- Build command: `npm run build`
- Publish directory: `dist`

Phase 1은 로컬 데모 저장소로 동작하며, Supabase 연결을 위한 스키마 초안은
`supabase/migrations`에 포함되어 있습니다. 마음체크는 사회적 연결·생활
리듬·마음 에너지·삶의 질을 6문항으로 돌아보는 비진단형 자가확인으로
동작하며, 결과는 위험도가 아닌 `마음 돌봄 1·2·3단계` 안내 등급으로
표시됩니다. 직접 적은 도움 요청 내용은 서버로 전송하지 않고 현재 기기에
초안으로만 저장됩니다. 지역 자원 화면은 광진구와 서울시의 공식 지원
페이지로 연결됩니다.

하단의 커뮤니티 탭은 회원 정보의 건물명을 사용해 건물별 이야기 피드를
구성합니다. 기본 예시 게시글 3개와 사진이 포함되어 있으며, 새 글 작성 시
익명 또는 호수·이름 공개를 선택할 수 있습니다. 데모 게시글과 작성한 글은
현재 기기에서만 동작합니다.
